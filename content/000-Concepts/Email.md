### sendemail

send email via linux terminal. using smtp authentication.

```sh
# send mail from terminal linux, using smtp authentication
sendemail -f test@supermagicorg.com -t dave.wizard@supermagic.org -u "config" -m "config" -s 192.168.186.199 -xu test@supermagicorg.com -xp "test" -a config.Library-ms 
# Dec 17 23:40:11 kali sendemail[115305]: Email was sent successfully!
```
