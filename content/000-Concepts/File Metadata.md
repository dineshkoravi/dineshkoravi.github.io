### exiftool

To manage metadata about a file.

```
exiftool -u -a filename.filetype
```

- All tools about steganography. https://0xrick.github.io/lists/stego/
- `stegcracker` - A tool that bruteforces passwords using `steghide`

### file

Tool for finding the contents of a file.

```
file filename.fileformat
```
